codeknit legge il codice sorgente e scrive una mappa compatta della sua struttura: funzioni, classi, metodi, variabili e le loro relazioni. Gli LLM possono leggere direttamente quella mappa, permettendo loro di pianificare refactoring su centinaia di file senza caricare ogni file nel contesto.

## Funzionalità

<CardGrid>
  <Card title="12 Linguaggi" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala e TypeScript. Vedi il [riferimento sul supporto linguistico](reference/language-support/).
  </Card>
  <Card title="Output compatto" icon="document">
    Estrae funzioni, classi, metodi, variabili e le loro relazioni in file `.skt` progettati per le finestre di contesto degli LLM. La minificazione basata su dizionario consente di risparmiare più token. Scegli tra le [modalità di output](guides/output-modes/) inline, directory-flat o directory-tree.
  </Card>
  <Card title="Analisi del grafo" icon="random">
    22 algoritmi individuano cicli, hub, dead code, god classes e colli di bottiglia. Un grafo HTML interattivo mostra come i simboli sono collegati. Vedi la [guida ai comandi del grafo](guides/graph-commands/).
  </Card>
  <Card title="Rilevamento duplicati" icon="magnifier">
    Il fingerprinting CTPH individua codice duplicato e quasi duplicato tra file e tra linguaggi. Vedi la [guida al comando fingerprint](guides/fingerprint-command/).
  </Card>
  <Card title="Pronto per l'AI" icon="rocket">
    Un plugin per Claude Code, Codex e Kiro aggiunge un'unica abilità `codeknit` che installa il binario per te. Vedi [Usa codeknit con assistenti AI](guides/ai-assistants/).
  </Card>
</CardGrid>
