codeknitはソースコードを読み込み、その構造のコンパクトなマップを作成します。関数、クラス、メソッド、変数、およびそれらの関係が含まれます。LLMはこのマップを直接読み取ることができるため、数百のファイルをコンテキストに読み込むことなく、リファクタリングを計画できます。

## 特徴

<CardGrid>
  <Card title="12言語対応" icon="translate">
    C、C++、C#、Go、Java、JavaScript、PHP、Python、Ruby、Rust、Scala、TypeScript。[言語サポートリファレンス](reference/language-support/)を参照してください。
  </Card>
  <Card title="コンパクトな出力" icon="document">
    関数、クラス、メソッド、変数、およびそれらの関係を、LLMのコンテキストウィンドウ用に設計された`.skt`ファイルに抽出します。辞書ベースのミニファイにより、さらにトークンを節約できます。インライン、`directory-flat`、または`directory-tree`の[出力モード](guides/output-modes/)から選択できます。
  </Card>
  <Card title="グラフ分析" icon="random">
    22のアルゴリズムがサイクル、ハブ、デッドコード、ゴッドクラス、ボトルネックを検出します。インタラクティブなHTMLグラフでシンボルの接続状況を表示します。[グラフコマンドガイド](guides/graph-commands/)を参照してください。
  </Card>
  <Card title="重複検出" icon="magnifier">
    CTPHフィンガープリントにより、ファイル間および言語間の重複コードや近似重複コードを検出します。[フィンガープリントガイド](guides/fingerprint-command/)を参照してください。
  </Card>
  <Card title="AI対応" icon="rocket">
    Claude Code、Codex、Kiro用のプラグインにより、`codeknit`スキルがバイナリを自動インストールします。[AIアシスタントとの連携](guides/ai-assistants/)を参照してください。
  </Card>
</CardGrid>
