codeknit liest Ihren Quellcode und erstellt eine kompakte Karte seiner **Codestruktur**: Funktionen, Klassen, Methoden, Variablen und deren Beziehungen. LLMs können diese Karte direkt lesen, sodass sie Refactorings über Hunderte von Dateien planen können, ohne jede Datei in den Kontext laden zu müssen.

## Funktionen

<CardGrid>
  <Card title="12 Sprachen" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala und TypeScript. Siehe die [Referenz zur Sprachunterstützung](reference/language-support/).
  </Card>
  <Card title="Kompakte Ausgabe" icon="document">
    Extrahiert Funktionen, Klassen, Methoden, Variablen und deren Beziehungen in `.skt`-Dateien, die für LLM-Kontextfenster entwickelt wurden. Wörterbuchbasierte Minimierung spart weitere Tokens. Wählen Sie zwischen inline, directory-flat oder directory-tree [Ausgabemodi](guides/output-modes/).
  </Card>
  <Card title="Graphanalyse" icon="random">
    22 Algorithmen finden Zyklen, Hubs, **dead code**, **god classes** und Engpässe. Ein interaktiver HTML-Graph zeigt, wie **Symbole** verbunden sind. Siehe den [Leitfaden zu Graphbefehlen](guides/graph-commands/).
  </Card>
  <Card title="Duplikaterkennung" icon="magnifier">
    **CTPH**-Fingerprinting findet Duplikate und Beinahe-Duplikate im Code über Dateien und Sprachen hinweg. Siehe den [Fingerprint-Leitfaden](guides/fingerprint-command/).
  </Card>
  <Card title="KI-Ready" icon="rocket">
    Ein Plugin für Claude Code, Codex und Kiro fügt eine einzelne `codeknit`-Fähigkeit hinzu, die das Binary für Sie installiert. Siehe [codeknit mit KI-Assistenten verwenden](guides/ai-assistants/).
  </Card>
</CardGrid>
