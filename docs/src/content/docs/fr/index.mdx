codeknit lit votre code source et écrit une carte compacte de sa structure : fonctions, classes, méthodes, variables, et leurs relations. Les LLM peuvent lire cette carte directement, ce qui leur permet de planifier des refactorisations sur des centaines de fichiers sans charger chaque fichier dans le contexte.

## Fonctionnalités

<CardGrid>
  <Card title="12 Langages" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala et TypeScript. Consultez la [référence de support des langages](reference/language-support/).
  </Card>
  <Card title="Sortie compacte" icon="document">
    Extrait les fonctions, classes, méthodes, variables et leurs relations dans des fichiers `.skt` conçus pour les fenêtres de contexte des LLM. La minification basée sur un dictionnaire permet d'économiser des tokens. Choisissez parmi les [modes de sortie](guides/output-modes/) inline, directory-flat ou directory-tree.
  </Card>
  <Card title="Analyse de graphe" icon="random">
    22 algorithmes détectent les dépendances cycliques, les hubs, le code mort, les god classes et les goulots d'étranglement. Un graphe HTML interactif montre comment les symboles sont connectés. Consultez le [guide des commandes de graphe](guides/graph-commands/).
  </Card>
  <Card title="Détection de doublons" icon="magnifier">
    Le fingerprinting CTPH détecte les doublons et les quasi-doublons dans le code, entre fichiers et entre langages. Consultez le [guide de la commande fingerprint](guides/fingerprint-command/).
  </Card>
  <Card title="Prêt pour l'IA" icon="rocket">
    Un plugin pour Claude Code, Codex et Kiro ajoute une seule compétence `codeknit` qui installe le binaire pour vous. Consultez [Utiliser codeknit avec des assistants IA](guides/ai-assistants/).
  </Card>
</CardGrid>
