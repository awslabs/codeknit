codeknit lee tu código fuente y escribe un mapa compacto de su estructura: funciones, clases, métodos, variables y cómo se relacionan. Los LLM pueden leer ese mapa directamente, por lo que pueden planificar refactorizaciones en cientos de archivos sin cargar cada archivo en el contexto.

## Características

<CardGrid>
  <Card title="12 Idiomas" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala y TypeScript. Consulta la [referencia de soporte de lenguajes](reference/language-support/).
  </Card>
  <Card title="Salida Compacta" icon="document">
    Extrae funciones, clases, métodos, variables y sus relaciones en archivos `.skt` diseñados para ventanas de contexto de LLM. La minificación basada en diccionario ahorra más tokens. Elige entre los [modos de salida](guides/output-modes/) inline, directory-flat o directory-tree.
  </Card>
  <Card title="Análisis de Grafo" icon="random">
    22 algoritmos encuentran ciclos, hubs, código muerto, god classes y cuellos de botella. Un grafo HTML interactivo muestra cómo se conectan los símbolos. Consulta la [guía de comandos de grafo](guides/graph-commands/).
  </Card>
  <Card title="Detección de Duplicados" icon="magnifier">
    La generación de fingerprints con CTPH encuentra código duplicado y casi duplicado en archivos y entre lenguajes. Consulta la [guía de fingerprints](guides/fingerprint-command/).
  </Card>
  <Card title="Listo para IA" icon="rocket">
    Un plugin para Claude Code, Codex y Kiro añade una única habilidad `codeknit` que instala el binario por ti. Consulta [Usar codeknit con asistentes de IA](guides/ai-assistants/).
  </Card>
</CardGrid>
