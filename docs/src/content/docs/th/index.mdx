`codeknit` อ่านซอร์สโค้ดของคุณและเขียนแผนที่ขนาดกะทัดรัดของโครงสร้างโค้ด ได้แก่ ฟังก์ชัน คลาส เมธอด ตัวแปร และความสัมพันธ์ระหว่างกัน LLM สามารถอ่านแผนที่นี้ได้โดยตรง ทำให้สามารถวางแผนการรีแฟคเตอร์ข้ามไฟล์หลายร้อยไฟล์โดยไม่ต้องโหลดทุกไฟล์เข้าไปในบริบท

## คุณสมบัติ

<CardGrid>
  <Card title="12 ภาษา" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala และ TypeScript ดูรายละเอียดใน [เอกสารอ้างอิงการรองรับภาษา](reference/language-support/)
  </Card>
  <Card title="เอาต์พุตขนาดกะทัดรัด" icon="document">
    สกัดฟังก์ชัน คลาส เมธอด ตัวแปร และความสัมพันธ์ระหว่างกันลงในไฟล์ `.skt` ที่ออกแบบมาสำหรับหน้าต่างบริบทของ LLM การย่อขนาดแบบใช้พจนานุกรมช่วยประหยัดโทเค็นได้มากขึ้น เลือกโหมดเอาต์พุตได้จาก inline, directory-flat หรือ directory-tree [โหมดเอาต์พุต](guides/output-modes/)
  </Card>
  <Card title="การวิเคราะห์กราฟ" icon="random">
    อัลกอริทึม 22 แบบค้นหาการวนรอบ ฮับ โค้ดที่ไม่ใช้งาน god classes และคอขวด กราฟ HTML แบบโต้ตอบแสดงการเชื่อมต่อของสัญลักษณ์ ดูรายละเอียดใน [คู่มือคำสั่งกราฟ](guides/graph-commands/)
  </Card>
  <Card title="การตรวจจับรายการซ้ำ" icon="magnifier">
    การทำ fingerprinting ด้วย CTPH ค้นหารายการซ้ำและรายการที่เกือบซ้ำของโค้ดข้ามไฟล์และข้ามภาษา ดูรายละเอียดใน [คู่มือคำสั่ง fingerprint](guides/fingerprint-command/)
  </Card>
  <Card title="พร้อมสำหรับ AI" icon="rocket">
    ปลั๊กอินสำหรับ Claude Code, Codex และ Kiro เพิ่มทักษะ `codeknit` เพียงอย่างเดียวที่ติดตั้งไบนารีให้คุณโดยอัตโนมัติ ดูรายละเอียดใน [ใช้ codeknit กับผู้ช่วย AI](guides/ai-assistants/)
  </Card>
</CardGrid>
