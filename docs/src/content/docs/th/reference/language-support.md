codeknit ดึงข้อมูลวากยสัมพันธ์โดยไม่ต้องเรียกใช้คอมไพเลอร์ ประเมินมาโคร หรือโหลดการพึ่งพาของโปรเจ็กต์ ตารางด้านล่างอธิบายโครงสร้างที่ผ่านการทดสอบ ไม่ใช่การปฏิบัติตามภาษาอย่างสมบูรณ์หรือการรับประกันการแก้ไขชื่อข้ามไฟล์

## การเลือกภาษาสำหรับไฟล์ส่วนหัว

คำสั่ง CLI ที่ประมวลผลซอร์สทั้งหมดยอมรับ `--header-language c|cpp` ตัวเลือกนี้ใช้ได้เฉพาะกับไฟล์ `.h` นามสกุลอื่น ๆ ยังคงใช้ตัวแยกวิเคราะห์ตามปกติ

```bash
codeknit parse ./src --header-language cpp
codeknit fingerprint ./src --header-language c
codeknit graph analyze ./src --header-language cpp
```

ค่าเริ่มต้นคือ `c` เพื่อรักษาการดึงข้อมูลมาโคร C, typedef และ union ใช้ `cpp` สำหรับส่วนหัว C++ ที่มีนามสกุล `.h`; ไฟล์ที่มีนามสกุล `.hpp` และ `.hxx` ใช้ C++ อยู่แล้ว ตัวเลือกนี้ชัดเจนเนื่องจากไวยากรณ์ทั้งสองสามารถยอมรับไวยากรณ์ของอีกภาษาหนึ่งได้โดยไม่ดึงโครงสร้างทั้งหมดออกมา

การป้องกันส่วนหัวและเงื่อนไขแบบมีเงื่อนไขจะถูกตรวจสอบโดยไม่ประเมินเงื่อนไข ผลลัพธ์จึงอาจรวมการประกาศจากสาขาที่กันไม่ให้ใช้งานพร้อมกันได้ การขยายมาโคร การแก้ไข include และแฟล็กการสร้างไม่ถูกนำมาใช้ อินเทอร์เฟซผู้ใช้แบบข้อความใช้การเลือก C เริ่มต้นสำหรับไฟล์ `.h`

## การรักษารูปแบบ API

ตัวอย่างเช่น Go:

```go
func Pair(a, b int, rest ...string) (string, error)
```

จะให้ผลลัพธ์เป็น:

```text
Pair(a: int, b: int, rest: ...string) -> (string, error)
```

เมธอดอินเทอร์เฟซ Go และฟิลด์ที่มีชื่อของ Go/Rust ปรากฏเป็นสัญลักษณ์ในทั้งโหมดปกติและโหมด fingerprint เมธอดและฟิลด์ยังคงรักษาประเภทที่เป็นเจ้าของ โมดูล Rust ที่ซ้อนกันยังคงรักษาชื่อที่มีคุณสมบัติ เช่น `service.storage.read` รวมถึงเมื่อโมดูลอื่นประกาศฟังก์ชันที่มีชื่อเดียวกัน

Rust อนุญาตให้ฟิลด์และเมธอดมีชื่อเดียวกัน ชื่อที่มีขอบเขตของฟิลด์มีคำต่อท้าย `#field` ภายในเพื่อให้ ID และเส้นเชื่อมการบรรจุยังคงแยกจากกัน ชื่อที่แสดงและลายเซ็นยังคงรักษาชื่อฟิลด์เดิม

ลายเซ็น Python ยังคงรักษาคำอธิบายประกอบ ค่าเริ่มต้น splats และตัวคั่นการเรียกใช้งาน พารามิเตอร์ `self` หรือ `cls` ตัวแรกตามแบบแผนจะถูกละเว้นจากเมธอดที่ถูกผูกไว้ แต่จะถูกเก็บไว้ในฟังก์ชันอิสระหรือเมธอดแบบคงที่

ลายเซ็นหลายบรรทัดยังคงรักษาการขึ้นบรรทัดใหม่ใน JSON SKT แปลงการขึ้นบรรทัดใหม่เป็น `\n` และ `\r` เพื่อให้แต่ละสัญลักษณ์อยู่ในบรรทัดเอาต์พุตเดียว

## ข้อจำกัดที่ทราบ

- ตัวประกาศตัวชี้ การอ้างอิง อาร์เรย์ และฟังก์ชันพอยน์เตอร์ของ C/C++ ที่ซับซ้อนอาจยังคงมีลายเซ็นที่ไม่สมบูรณ์ การประกาศที่สร้างจากมาโครไม่ถูกขยาย
- การจัดการคอนสตรัคเตอร์ของ TypeScript/JavaScript และรูปแบบพารามิเตอร์แบบออปชัน rest หรือ destructured บางรูปแบบยังไม่สมบูรณ์
- ข้อจำกัด generic ขั้นสูงและรูปแบบประเภทที่อยู่นอกกรณีที่ทดสอบจะแตกต่างกันไปตามภาษา ประเภทการคืนค่าไม่ถูกอนุมาน
- มาโคร Rust ไม่ถูกขยาย การประกาศโมดูลนอกบรรทัดถูกบันทึก; ไฟล์ของโมดูลเหล่านั้นต้องถูกรวมไว้ในการสแกน ฟิลด์ทูเพิล รายละเอียดของ enum variant และรายการที่เกี่ยวข้องมีการครอบคลุมบางส่วน
- การดึงข้อมูลวากยสัมพันธ์ไม่ได้แก้ไขการส่งต่อแบบไดนามิก การโอเวอร์โหลด การนำเข้าการพึ่งพา หรือความหมายการกำหนดค่าการสร้างด้วยความแม่นยำของคอมไพเลอร์
- ข้อผิดพลาดทางวากยสัมพันธ์บางส่วนอาจยังคงละเว้นการประกาศ ตรวจสอบคำเตือนที่รายงานและตรวจสอบซอร์สก่อนใช้การปรับโครงสร้างใหม่

การดึงข้อมูลที่สมบูรณ์ยิ่งขึ้นจะเปลี่ยนจำนวนสัญลักษณ์และ ShortID สั้น ๆ สร้างเอาต์พุตโครงร่างที่มีอยู่ใหม่เมื่ออัปเกรดแทนที่จะผสมกับเอาต์พุตเก่า
