คำสั่งที่เกี่ยวข้องกับการประมวลผลซอร์สโค้ดทั้งหมดยอมรับ `--header-language c|cpp` สำหรับไฟล์ `.h` โดยค่าเริ่มต้นคือ `c` เลือก `cpp` สำหรับเฮดเดอร์ C++ ที่ตั้งชื่อเป็น `.h` ส่วนนามสกุลอื่น ๆ จะไม่ได้รับผลกระทบ ดูรายละเอียดเพิ่มเติมที่ [การรองรับภาษา](../language-support/) สำหรับนโยบายการเลือกและความสามารถในการดึงข้อมูลที่ผ่านการทดสอบ

## codeknit

เปิดใช้งานอินเทอร์เฟซผู้ใช้แบบ terminal แบบโต้ตอบ (TUI) ซึ่งจะแนะนำคุณผ่านคำสั่งและตัวเลือกที่มีอยู่

```bash
codeknit
```

## codeknit parse

ดึงข้อมูลโครงสร้างจากซอร์สโค้ดไปยังไฟล์ `.skt` หรือ JSON

```bash
codeknit parse <input-path> [output-dir]
```

| ฟลैก             | ประเภท   | ค่าเริ่มต้น          | คำอธิบาย                                                                            |
| ---------------- | ------ | ---------------- | -------------------------------------------------------------------------------------- |
| `--output-mode`  | string | `directory-flat` | โหมดเอาต์พุต: `inline`, `directory-flat`, หรือ `directory-tree`                           |
| `--format`       | string | `skt`            | รูปแบบเอาต์พุต: `skt` หรือ `json`                                                         |
| `--max-lines`    | int    | `500`            | จำนวนบรรทัดสูงสุดต่อไฟล์เอาต์พุต (ใช้กับโหมด `directory-flat` และ `directory-tree`) |
| `--collect-test` | bool   | `false`          | รวมไฟล์ทดสอบในการวิเคราะห์                                                         |
| `--minify`       | bool   | `false`          | เปิดใช้งานการย่อขนาดเอาต์พุตโดยใช้พจนานุกรม                                            |
| `--edges`        | bool   | `false`          | รวมส่วน `[edges]` ในเอาต์พุต (ปิดไว้ตามค่าเริ่มต้นเพื่อประหยัดโทเค็น)                |
| `--clean`        | bool   | `false`          | ลบไฟล์ `.skt` ที่ไม่ได้ใช้งานออกจากไดเรกทอรีเอาต์พุตก่อนเขียน                     |
| `--workers`      | int    | `0` (NumCPU)     | จำนวน goroutines การแยกวิเคราะห์สูงสุดที่ทำงานพร้อมกัน                                                  |
| `--verbose`      | bool   | `false`          | แสดงข้อมูลความคืบหน้าในระหว่างการประมวลผล                                           |

ไดเรกทอรีเอาต์พุตจะมีค่าเริ่มต้นเป็น `./skeleton` เมื่อไม่ได้ระบุ ในโหมด `inline` เอาต์พุตจะถูกเขียนไปยัง stdout และไม่มีการใช้ไดเรกทอรี เมื่อใช้ `--format json` เอาต์พุตไดเรกทอรีจะถูกเขียนเป็น `codeknit.json`

## codeknit graph show

สร้างการแสดงกราฟ HTML แบบโต้ตอบของโครงสร้างโค้ดเบส

```bash
codeknit graph show <input-path>
```

| ฟลैก             | ประเภท   | ค่าเริ่มต้น                          | คำอธิบาย                                  |
| ---------------- | ------ | -------------------------------- | -------------------------------------------- |
| `-o`, `--output` | string | `./skeleton/codeknit-graph.html` | เส้นทางไฟล์ HTML เอาต์พุต                        |
| `--collect-test` | bool   | `false`                          | รวมไฟล์ทดสอบในการวิเคราะห์               |
| `--workers`      | int    | `0` (NumCPU)                     | จำนวน goroutines การแยกวิเคราะห์สูงสุดที่ทำงานพร้อมกัน        |
| `--verbose`      | bool   | `false`                          | แสดงข้อมูลความคืบหน้าในระหว่างการประมวลผล                      |

ไฟล์ HTML ที่สร้างขึ้นจะเป็นแบบ self-contained และจะเปิดขึ้นโดยอัตโนมัติในเบราว์เซอร์เริ่มต้นของคุณ

## codeknit graph analyze

เรียกใช้งานอัลกอริทึมการวิเคราะห์โครงสร้างและส่งออกรายงาน `.skt` ที่อ่านได้โดย LLM

```bash
codeknit graph analyze <input-path>
```

| ฟลैก                      | ประเภท    | ค่าเริ่มต้น                         | คำอธิบาย                                                   |
| ------------------------- | ------- | ------------------------------- | ------------------------------------------------------------- |
| `-o`, `--output`          | string  | `./skeleton/graph_analysis.skt` | เส้นทางไฟล์ `.skt` เอาต์พุต                                       |
| `--collect-test`          | bool    | `false`                         | รวมไฟล์ทดสอบในการวิเคราะห์                                |
| `--workers`               | int     | `0` (NumCPU)                    | จำนวน goroutines การแยกวิเคราะห์สูงสุดที่ทำงานพร้อมกัน                         |
| `--verbose`               | bool    | `false`                         | แสดงข้อมูลความคืบหน้าในระหว่างการประมวลผล                  |
| `--fan-threshold`         | int     | `10`                            | ค่า fan-in หรือ fan-out ขั้นต่ำในการระบุสัญลักษณ์ฮับ                |
| `--god-threshold`         | int     | `15`                            | จำนวนเส้นเชื่อม contains ขั้นต่ำในการระบุ god class/function      |
| `--max-inheritance-depth` | int     | `5`                             | ระบุเชนการสืบทอดที่ลึกกว่าค่านี้                |
| `--top-n`                 | int     | `30`                            | จำกัดส่วนเอาต์พุตที่จัดอันดับ `0` หมายถึงไม่มีการจำกัด                |
| `--betweenness-threshold` | float64 | `0.001`                         | ค่าความสำคัญระหว่างกลางขั้นต่ำที่จะรายงาน                |
| `--propagation-cutoff`    | float64 | `0.05`                          | ค่าความน่าจะเป็นขั้นต่ำในการดำเนินการจำลองการแพร่กระจายการเปลี่ยนแปลง |

## codeknit graph hotspots

จัดอันดับไฟล์โดยใช้ประวัติ Git และความสำคัญของโครงสร้าง และรายงานการเชื่อมโยงชั่วคราวระหว่างไฟล์ที่มีการเปลี่ยนแปลงร่วมกันซ้ำ ๆ

```bash
codeknit graph hotspots <input-path>
```

| ฟลैก                     | ประเภท   | ค่าเริ่มต้น                   | คำอธิบาย                                     |
| ------------------------ | ------ | ------------------------- | ----------------------------------------------- |
| `-o`, `--output`         | string | `./skeleton/hotspots.skt` | เส้นทางไฟล์เอาต์พุต                                |
| `--format`               | string | `skt`                     | รูปแบบเอาต์พุต: `skt` หรือ `json`                  |
| `--since`                | string | `12mo`                    | ช่วงเวลาประวัติ เช่น `180d`, `12mo`, หรือ `2y` |
| `--max-commits`          | int    | `2000`                    | จำนวนคอมมิตสูงสุดที่จะตรวจสอบ                      |
| `--max-files-per-commit` | int    | `50`                      | ไม่รวมคอมมิตที่เปลี่ยนแปลงไฟล์จำนวนมาก             |
| `--min-cochanges`        | int    | `3`                       | จำนวนคอมมิตที่ใช้ร่วมกันขั้นต่ำสำหรับการเชื่อมโยงชั่วคราว    |
| `--top-n`                | int    | `30`                      | จำนวนผลลัพธ์สูงสุดต่อส่วนรายงาน              |
| `--include-merges`       | bool   | `false`                   | รวมคอมมิตการผสาน                           |
| `--collect-test`         | bool   | `false`                   | รวมไฟล์ทดสอบ                              |
| `--workers`              | int    | `0` (NumCPU)              | จำนวน goroutines การแยกวิเคราะห์สูงสุดที่ทำงานพร้อมกัน           |
| `--verbose`              | bool   | `false`                   | แสดงข้อมูลความคืบหน้า                      |

## codeknit fingerprint

ตรวจจับโค้ดที่ซ้ำและรายการที่เกือบซ้ำโดยใช้ fuzzy hashing

```bash
codeknit fingerprint <input-path>
```

| ฟลैก               | ประเภท   | ค่าเริ่มต้น                       | คำอธิบาย                                                                                                                            |
| ------------------ | ------ | ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `-o`, `--output`   | string | `./skeleton/fingerprints.skt` | เส้นทางไฟล์ `.skt` เอาต์พุต                                                                                                                |
| `--min-similarity` | int    | `65`                          | ค่าความคล้ายคลึงขั้นต่ำที่จะรายงาน (0–100)                                                                                        |
| `--max-similarity` | int    | `95`                          | ค่าความคล้ายคลึงสูงสุดที่จะรายงาน (0–100)                                                                                        |
| `--show-all`       | bool   | `false`                       | รวมส่วน `[fingerprints]` พร้อมข้อมูลโทเค็นดิบ                                                                               |
| `--rerank`         | bool   | `false`                       | ค้นหาเพื่อนบ้านเชิงความหมายและจัดอันดับใหม่โดยใช้การฝัง Ollama (ต้องใช้ `ollama serve` และ `ollama pull qwen3-embedding:0.6b`) |
| `--model`          | string | `qwen3-embedding:0.6b`        | โมเดลการฝัง Ollama ที่จะใช้กับ `--rerank`                                                                                          |
| `--collect-test`   | bool   | `false`                       | รวมไฟล์ทดสอบในการวิเคราะห์                                                                                                         |
| `--workers`        | int    | `0` (NumCPU)                  | จำนวน goroutines การแยกวิเคราะห์สูงสุดที่ทำงานพร้อมกัน                                                                                                  |
| `--verbose`        | bool   | `false`                       | แสดงข้อมูลความคืบหน้าในระหว่างการประมวลผล                                                                                           |

## codeknit completion

สร้างสคริปต์การเติมคำอัตโนมัติสำหรับเชลล์ที่รองรับ

```bash
codeknit completion <shell>
```

เชลล์ที่รองรับ: `bash`, `zsh`, `fish`, `powershell`

## ฟลैกทั่วไป

| ฟลैก           | คำอธิบาย                       |
| -------------- | --------------------------------- |
| `--version`    | แสดงข้อมูลเวอร์ชัน         |
| `--help`, `-h` | แสดงความช่วยเหลือสำหรับคำสั่งปัจจุบัน |
