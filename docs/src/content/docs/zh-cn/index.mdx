codeknit 读取源代码并生成其结构的紧凑映射：函数、类、方法、变量及其相互关系。LLM 可以直接读取该映射，从而能够在不将每个文件加载到上下文的情况下，规划跨越数百个文件的重构。

## 特性

<CardGrid>
  <Card title="12 种语言" icon="translate">
    C、C++、C#、Go、Java、JavaScript、PHP、Python、Ruby、Rust、Scala 和 TypeScript。请参阅[语言支持参考](reference/language-support/)。
  </Card>
  <Card title="紧凑输出" icon="document">
    提取函数、类、方法、变量及其关系，生成专为 LLM 上下文窗口设计的 `.skt` 文件。基于字典的压缩可节省更多 token。可选择内联、目录扁平化或目录树等[输出模式](guides/output-modes/)。
  </Card>
  <Card title="图分析" icon="random">
    22 种算法可发现循环依赖、中心节点、死代码、god classes 和瓶颈。交互式 HTML 图展示符号之间的连接方式。请参阅[图命令指南](guides/graph-commands/)。
  </Card>
  <Card title="重复检测" icon="magnifier">
    CTPH 指纹识别可发现跨文件和跨语言的重复和近似重复代码。请参阅[指纹命令指南](guides/fingerprint-command/)。
  </Card>
  <Card title="AI 就绪" icon="rocket">
    Claude Code、Codex 和 Kiro 的插件添加了单个 `codeknit` 技能，可为您安装二进制文件。请参阅[将 codeknit 与 AI 助手配合使用](guides/ai-assistants/)。
  </Card>
</CardGrid>
