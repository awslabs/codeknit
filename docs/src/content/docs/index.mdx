codeknit reads your source code and writes a compact map of its structure: functions, classes, methods, variables, and how they relate. LLMs can read that map directly, so they can plan refactors across hundreds of files without loading every file into context.

## Features

<CardGrid>
  <Card title="12 Languages" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala, and TypeScript. See the [language support reference](reference/language-support/).
  </Card>
  <Card title="Compact Output" icon="document">
    Extracts functions, classes, methods, variables, and their relationships into `.skt` files designed for LLM context windows. Dictionary-based minification saves more tokens. Choose from inline, directory-flat, or directory-tree [output modes](guides/output-modes/).
  </Card>
  <Card title="Graph Analysis" icon="random">
    22 algorithms find cycles, hubs, dead code, god classes, and bottlenecks. An interactive HTML graph shows how symbols connect. See the [graph commands guide](guides/graph-commands/).
  </Card>
  <Card title="Duplicate Detection" icon="magnifier">
    CTPH fingerprinting finds duplicate and near-duplicate code across files and across languages. See the [fingerprint guide](guides/fingerprint-command/).
  </Card>
  <Card title="AI-Ready" icon="rocket">
    A plugin for Claude Code, Codex, and Kiro adds a single `codeknit` skill that installs the binary for you. See [Use codeknit with AI assistants](guides/ai-assistants/).
  </Card>
</CardGrid>
