codeknit membaca kode sumber Anda dan menulis peta ringkas dari strukturnya: fungsi, kelas, metode, variabel, dan bagaimana mereka saling berhubungan. LLM dapat membaca peta tersebut secara langsung, sehingga mereka dapat merencanakan refaktor di ratusan file tanpa perlu memuat setiap file ke dalam konteks.

## Fitur

<CardGrid>
  <Card title="12 Bahasa" icon="translate">
    C, C++, C#, Go, Java, JavaScript, PHP, Python, Ruby, Rust, Scala, dan TypeScript. Lihat [referensi dukungan bahasa](reference/language-support/).
  </Card>
  <Card title="Keluaran Ringkas" icon="document">
    Mengekstrak fungsi, kelas, metode, variabel, dan hubungan mereka ke dalam file `.skt` yang dirancang untuk jendela konteks LLM. Minifikasi berbasis kamus menghemat lebih banyak token. Pilih dari [mode keluaran](guides/output-modes/) inline, directory-flat, atau directory-tree.
  </Card>
  <Card title="Analisis Graf" icon="random">
    22 algoritma menemukan dependensi siklik, pusat, kode mati, god class, dan hambatan. Graf HTML interaktif menampilkan bagaimana simbol saling terhubung. Lihat [panduan perintah graf](guides/graph-commands/).
  </Card>
  <Card title="Deteksi Duplikat" icon="magnifier">
    Fingerprinting CTPH menemukan kode duplikat dan hampir duplikat di seluruh file dan bahasa. Lihat [panduan fingerprint](guides/fingerprint-command/).
  </Card>
  <Card title="Siap AI" icon="rocket">
    Plugin untuk Claude Code, Codex, dan Kiro menambahkan satu keterampilan `codeknit` yang menginstal biner untuk Anda. Lihat [Gunakan codeknit dengan asisten AI](guides/ai-assistants/).
  </Card>
</CardGrid>
